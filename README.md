# ActionCam+

Android-приложение для Wi‑Fi action-камеры `ActionCam_b40418003072`, совместимой с протоколом Generalplus / GoPlus Cam.

## Скачать APK

Готовая APK-сборка публикуется автоматически после успешного GitHub Actions билда:

**https://github.com/coldoon11/ActionCamWifi/releases/latest/download/ActionCamPlus.apk**

Исходники и автоматическая сборка будут добавлены следующим коммитом.

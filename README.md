# ActionCam+

Android-приложение для Wi‑Fi action-камеры **ActionCam_b40418003072** (WPA2: **12345678**), совместимой с Generalplus / GoPlus Cam.

## Скачать APK

После успешной автоматической сборки APK будет доступен по постоянной ссылке:

**https://github.com/coldoon11/ActionCamWifi/releases/latest/download/ActionCamPlus.apk**

Репозиторий: https://github.com/coldoon11/ActionCamWifi

## Что умеет

- системное подключение Android к Wi‑Fi камеры;
- автоматический поиск Generalplus TCP-порта 8081;
- чтение списка фото и видео с карты памяти;
- скачивание оригинальных файлов с прогрессом в `DCIM/ActionCamPlus`;
- определение AVI / MOV / MP4 после скачивания;
- удаление файла с карты камеры;
- старт/стоп записи и создание фото;
- запуск RTSP live-потока `rtsp://<camera-ip>:8080/?action=stream` через установленный видеоплеер.

## Важно

Это тестовая сборка под конкретную камеру пользователя. Протокол основан на публичном Generalplus GoPlusCam SDK. Поскольку физической камеры у сборочной системы нет, совместимость конкретной прошивки проверяется установкой APK на телефон.

Минимальная версия Android: **10 (API 29)**.
